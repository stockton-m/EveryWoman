# EveryWoman site copy

This is the wording on everywoman.io as of October 2026, for review and edits.

**Bold** marks words that differ from the October 2026 notes, in both the current line and the original line. If a line matches those notes exactly, nothing is bold. If Original is blank, that line was written for the site and was not in the October notes.

Slop indicators are blank when a line is clean. They call out:

- Em dashes (—)
- Semicolons
- Contrastive phrasing such as “it’s not X, it’s Y”
- Placeholder, empty, or unfinished text
- **PMOS**, where the usual term is PCOS (the October notes use PMOS as well)

Essay bodies and social captions are not in this table. Essay titles are. Some words are also styled bold or italic on the site itself. That styling is named in the Copy column, so it is not confused with the bold diff.
